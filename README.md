# S4W — PowerShell Tools

A collection of PowerShell utilities for enterprise IT workflows.

## Projects

### [DailyAppUpdate](Projects/DailyAppUpdate/README.md)
Automated daily downloader for enterprise applications using Evergreen and manual URLs. MSI-first, x64-preferred, offline-capable.

### [TransferDriveTool](Projects/TransferDriveTool/README.md)
MPN DTA Tool — a PowerShell GUI application for secure, compliant file transfers between drives with hash verification, logging, and audit trails.

### [OSDWebSRV-MPN](Projects/OSDWebSRV-MPN/README.md)
ASP.NET Core 8 web API for MECM OSD task sequences — accepts WinPE log uploads and serves driver package lookups. Personal fork, tuned for my environment.

### [MISC-SCRIPTS](Projects/MISC-SCRIPTS)
Configures Power BI Report Server (PBIRS) to use a Subject Alternative Name (SAN) certificate, with a Pester test suite.

Design docs and plans for these projects live centrally under `docs/superpowers/`, organized by feature slug rather than per-project.
